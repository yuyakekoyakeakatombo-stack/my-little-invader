# My Little Invader

2色LCD風の画面で遊ぶ育成ゲーム。UFOが置いていったたまごを育てて、育て方で進化先が変わります。単一のHTML/JSで動く、スマートフォンのホーム画面アプリとして遊べるプロトタイプです。

## 遊び方（テスター向け）

スマートフォンのブラウザで下記URLを開いてください。インストールや会員登録は不要です。

**https://yuyakekoyakeakatombo-stack.github.io/my-little-invader/**

### 📖 とりあつかいせつめいしょ

初めての方は、こちらに全部書いてあります（QRコード・ホーム画面への追加手順つき）。

**https://yuyakekoyakeakatombo-stack.github.io/my-little-invader/manual.html**

### ホーム画面に追加すると全画面で遊べます

**iPhone / iPad（Safari）**
1. Safari で上のURLを開く（他のブラウザでは追加できないことがあります）
2. 共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選ぶ
4. 右上の「追加」をタップ

**Android（Chrome）**
1. Chrome で上のURLを開く
2. 右上の ︙ をタップ
3. 「ホーム画面に追加」または「アプリをインストール」を選ぶ

PCのブラウザでも動きますが、スマートフォンでの全画面表示を想定してデザインしています。

## 操作

| ボタン | はたらき |
|---|---|
| 十字 | カーソル移動 / ヘッダーのマークを選択（上で選ぶ→A） |
| A | 決定 |
| B | 戻る |
| MENU | メニューを開く。お世話はここから |

MENU の中身：

- **お世話アイコン6つ**（2段×3列）— ごはん / そうじ / くすり / ほめる / しかる / ゲーム
- **STATUS** — おなか・きげん・なかよし・けんこう・せいちょう・タイプ
- **DIARY** — キャラが自分で書く日記（中間体になると出現）
- **SETTINGS** — げんご / てんき / サウンド / カラー / リセット
- **STORY** — この子が来た経緯
- **MANUAL** — 取扱説明書（`manual.html` をゲーム内に重ねて表示。ホーム画面アプリの全画面表示から抜けないため）

## ゲームの流れ

1. **名前をつける**（英数字 A-Z・0-9 で1〜7文字。**あとから変更できません**）
2. たまごから生まれ、世話をしながら育てる
3. 育て方で進化先が分岐（何が影響するかは伏せてあります）
4. エンディングは複数パターン。終わると新しいたまごが来る（日記は残る）

1周およそ2〜3週間です。

## 天気と位置情報

SETTINGS →「てんき」で3つから選べます。

| 設定 | 位置情報 |
|---|---|
| オフ | 不要 |
| とし（世界の主要12都市から選択） | **不要** |
| げんざいち | 必要（許可を求める前に用途を表示） |

位置情報は、ゲームに反映される天気を取得する目的にのみ使用します。その他の目的で、保存および第三者へ提供されることはありません。

## 収録ミニゲーム

| ゲーム | 操作 | 内容 |
|---|---|---|
| **SPACEWALK** | 十字で上下左右 | デブリをよける。30秒でUFOが出現。5回ミスで終了 |
| **SHOOTING STAR** | 十字左右 / A で撃つ | 流れ星に当てて得点。逃すと減点 |
| **ABDUCTION** | 十字左右 / A でジャンプ | UFOのビームから逃げる。長く生き延びる |

各ゲームのタイトル画面で「HOW TO PLAY」を選ぶと遊び方を確認できます。

## 注意

- **セーブデータは端末のブラウザ内（localStorage）に保存されます。** 端末ごとに独立していて、他の端末には引き継げません。ブラウザの閲覧データを削除すると消えます。
- **リアルタイム進行です。** 閉じている間も時間が経過した分だけ育ちます。
- **オフラインでも遊べます。** 一度開くとゲーム一式が端末に保管され、以後は圏外でも起動します（初回だけ通信が必要）。
- 言語（EN/日本語）は SETTINGS から切り替えできます。

## 開発メモ

### Service Worker（オフライン対応）

`sw.js` がゲーム一式を端末にキャッシュします。**キャッシュ名は `sw.js` の `VERSION` から作られるので、
配信するファイルを直したら必ず上げること。**上げないとテスターの端末に古い版が出続けます。

自動化してあるので、クローン後に一度だけ以下を実行してください。

```sh
sh tools/install-hooks.sh
```

これで pre-commit フックが入り、**コミットのたびに回帰テストが走り**、配信対象のファイルを
直していれば `VERSION` が自動で上がります。手動で上げたいときは `sh tools/bump-sw.sh`。

### テスト

ブラウザを開かずに、育成本体とミニゲームを Node に読み込んで動かします。
ゲームのソースには手を入れず、読み込むときだけ取り出し口を差し込む作りです。

```sh
node tools/test.js       # 育成本体（なかよし・進化・エンディング・日記・セーブ移行 ほか）
node tools/mg-test.js    # ミニゲーム3本（当たり判定・得点・残機・スポーンの決まり）
```

テスト自体が機能しているかは、わざと壊して落ちるかを見て確かめます。

```sh
node tools/mutate.js     # 育成本体
node tools/mg-mutate.js  # ミニゲーム
```

この2つは本体を書き換えてから戻すので、**同時に走らせないでください**（錠で弾きます）。
異常終了して `tools/.mutate.lock` が残った場合は消してから実行します。

更新の届きかた：新しい版を見つけると画面下に「あたらしい バージョンが あります」と出ます。
**勝手にリロードはしません**（プレイ中に画面が入れ替わらないように）。「よみこみなおす」を押すと切り替わります。

### フォント

Press Start 2P は `pressstart2p-latin.woff2` として同梱しています（SIL OFL 1.1 / `PressStart2P-OFL.txt`）。
Google Fonts から読むとオフラインで字が出なくなるため、外部参照は持っていません。

### 説明書

`manual.html` はテスター向けの取扱説明書です。画面図やアイコンは `invader_game.html` のスプライト定義から
生成しているので、キャラの絵を直したら作り直す必要があります。
