# My Little Invader

レトロな2色LCD風の育成ゲーム（たまごっち風）。インベーダーの卵を育てて、世話の仕方で進化先が変わります。単一のHTML/JSで動く、iPhoneのホーム画面アプリとして遊べるプロトタイプです。

## 遊び方（テスター向け）

iPhoneの **Safari** で下記URLを開いてください：

**https://USERNAME.github.io/REPO/invader_game.html**

> フルスクリーンで遊ぶには「ホーム画面に追加」がおすすめです。
> 1. 共有ボタン（□に↑）をタップ
> 2. 「ホーム画面に追加」を選ぶ
> 3. 追加されたアイコンから起動すると、URLバーの出ない全画面表示になります

Androidや PC のブラウザでも動作しますが、iPhoneでの全画面表示を想定してデザインしています。

## 操作

- **十字ボタン**：カーソル移動 / キャラの選択
- **A ボタン**：決定
- **B ボタン**：戻る
- **MENU**：世話メニュー（ごはん・掃除・ミニゲーム・くすり・ほめる・しかる）

## ゲームの流れ

1. 名前をつける（英字・ひらがな・カタカナ切替可）
2. 卵から生まれ、世話をしながら育てる
3. 世話の頻度・空腹・天気・ミニゲームの遊び方などで進化先が分岐
4. 進化・エンディングは複数パターン

言語（EN/JP）はメニューの SETTINGS から切り替えできます。

## 注意

- セーブデータは端末のブラウザ内（localStorage）に保存されます。端末ごとに独立し、他の人のデータと混ざりません。
- リアルタイム進行です。アプリを閉じている間も時間が経過した分だけ育ちます。

## 収録ミニゲーム

- **SPACEWALK** — 障害物をよけるドッジ系
- **SHOOTINGSTAR** — 流れ星をキャッチ
- **ABDUCTION** — UFOで対象を捕獲
